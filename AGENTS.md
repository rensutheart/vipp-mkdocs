# Working on the VIPP manual

- Read `CONTRIBUTING.md` for ownership, concise writing, version boundaries,
  and required documentation checks.
- This repository is the sole public manual. Do not recreate guides in
  napari-vipp; retain its plans, architecture/contracts, tests, and release
  evidence there and link to them when needed.
- Use short task pages plus focused reference pages, not a second monolithic
  user guide. Preserve scientific caveats and distinguish unreleased changes.
- Follow `docs/developer/docs-releases.md` only when publication is requested.
