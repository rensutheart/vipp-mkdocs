# VIPP 0.16.0a8

VIPP 0.16.0a8 improves Windows updates, recovery of multiple interrupted
workspaces, and everyday graph, inspector and viewer controls. Unfinished AI
assistant, agent, MCP and webhook features are not included.

Use the [canonical GitHub release](https://github.com/rensutheart/napari-vipp/releases/tag/v0.16.0a8)
for the exact wheel, source archive, unsigned Windows installer, separate
CPU-only unsigned/unnotarized macOS packages and matching checksums, or the
[exact PyPI version](https://pypi.org/project/napari-vipp/0.16.0a8/).
Follow the [installation instructions](../getting-started/installation.md).

## Choose a Windows update method

Review the selected method before approving setup. **Automatic** prefers an
eligible **In-place** update, which retains compatible packages and backs up
files changed by the update. Save your work and keep VIPP closed throughout
this method, including rollback or recovery. It does not keep a separate
runnable copy of the old environment. **Replacement** copies verified
compatible packages into a separate candidate; **Fresh** installs a complete
candidate. Setup stops when an explicitly selected method is unavailable.

Setup shows the current stage, measured counts when known, elapsed time and
diagnostic snapshots. A stale Windows registration can be repaired separately
only after setup verifies its ownership and you approve the repair. Setup
does not force-close VIPP or bypass an unverified registration. See
[Windows update methods](../getting-started/installation.md#windows-update-methods).

## Recover several workspaces

Check the workspaces you want, then recover them into new unsaved tabs or
explicitly confirm discarding those recovery copies. Ordinary saved workflows
are not deleted or overwritten. Recovery still rebuilds only safe automatic
results; manual and file-writing steps remain paused. It does not restore
Batch configuration, source data or cached results. See
[workflow recovery](../how-to/save-share-export.md#recover-interrupted-workflows).

## Inspect results without changing them

- Inspector controls fit narrow docks, and scrolling past a parameter does
  not change it. **Node details…** shows a read-only snapshot of configured
  settings; the inspector remains where you edit them.
- Graph dimension controls, source-loading progress, node search, table
  columns and clearer **Open full table…** / **Export…** actions make it
  easier to find and inspect a result.
- **Viewer graphics** chooses the renderer for the next standalone Windows
  launch, separately from workflow Compute. A large intensity image can have
  a labelled, reduced-resolution 3D preview; 2D inspection remains
  full-resolution, and masks and labels are not reduced for display.
- Hysteresis Threshold avoids a full-volume float64 temporary while retaining
  its threshold and mask behavior. Connected-component labeling still
  needs memory for the plane or volume being processed.

## Compatibility and limits

Workflow, batch-config and manifest schemas remain **6**. Display previews
do not change scientific data, measurements or saved output. Keep original
workflows and data, regenerate Python exports with the installed version,
and recheck representative results.

The [qualification declaration](https://github.com/rensutheart/napari-vipp/blob/v0.16.0a8/docs/release-qualification-baseline.md)
separates changed-domain checks from carried-forward evidence. Installer
checks do not establish support for every existing package layout or a full
fresh-user installer lifecycle. Renderer choices do not expand scientific
GPU admission.
