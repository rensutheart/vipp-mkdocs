# VIPP 0.16.0a10

VIPP 0.16.0a10 is an alpha patch for reopening workflows, live Crop bounds
and explicit image-reader refresh. Scientific calculations, runtime dependency
pins and schema numbers are unchanged. All AI application features, including
assistant, agent, MCP and webhook work, are excluded from this 0.16 patch.

Use the [canonical GitHub release](https://github.com/rensutheart/napari-vipp/releases/tag/v0.16.0a10)
for the exact Python wheel and source archive, unsigned Windows x86-64
installer, and separate unsigned, unnotarized, CPU-only macOS Apple Silicon
and Intel packages with their installer checksums and provenance sidecars.
The Python package is also on the
[exact PyPI version page](https://pypi.org/project/napari-vipp/0.16.0a10/).
Follow the [installation instructions](../getting-started/installation.md).

## Reopen a recent workflow

- **Workflow actions → Open Recent** lists the ten most recently opened or
  saved workflows, newest first, using their full file paths.
- The list persists between launches. Built-in examples, cancelled opens and
  failed opens are not added.
- Selecting an entry uses the ordinary workflow checks and opens a new tab,
  keeping other workflows and unsaved edits intact.
- Missing or offline files remain in the list. Restore access, or use **Open**
  to choose a moved file's new location.
- **Clear recent workflows** clears only this history, not the workflow files.
  The history is a list of paths, not a backup or a recovery archive.

See [Open a workflow](../how-to/save-share-export.md#open-a-workflow).

## Read live Crop bounds clearly

- On Windows with Intel or unidentified graphics, **Crop Stack** keeps the
  input visible in 2D while you adjust its live outline. Pixels outside the
  outline remain visible so you can compare the retained and excluded regions.
- The outline is orange on a retained slice and red on an excluded slice.
  On a maximum-intensity projection, orange means at least one slice in the
  displayed slab intersects the crop—not that every projected slice is retained.
- The projection still shows the input, not a projection of the cropped result.
  Inspect the calculated output before continuing the analysis.
- Switch to 3D to view the same bounds as a wireframe, then back to 2D for
  individual slices. A loaded source window stays at its calibrated position.
- The Inspector also provides a **Crop bounds (schematic)** diagram. This
  presentation does not change output thumbnails, scientific crop values or
  the **Compute** setting.
- To try the guarded display mode elsewhere, set
  `VIPP_SAFE_CROP_PREVIEW=1` for that VIPP process. It is a viewer choice,
  not a different scientific calculation or a new compute backend.

See [Crop an image or volume](../how-to/crop-images.md).

## Deliberately accept a changed image reader

- A saved image reader or version may interpret the same source differently.
  The warning offers **Refresh file sources** as an explicit action; it does
  not silently accept the changed reader.
- The warning action and the graph toolbar's **Refresh** reload the current
  graph's file sources, not just the selected node.
- Check the preview, channels, axes and calibration before saving the workflow.
- For a collection, **Refresh** reloads the representative sample. Review its
  folder and pattern under **Batch workflow → Setup**, then use **Check batch**
  to verify the collection separately. That check does not run the batch.

See [The saved image reader has changed](../troubleshooting/common-pitfalls.md#the-saved-image-reader-has-changed).

## Compatibility and qualification boundary

Workflow, Batch configuration and manifest schemas remain **6**. Windows update
methods, installer ownership rules and scientific GPU admission are unchanged.
Keep original workflows and data and recheck representative results. macOS
remains CPU-only; this release does not add Apple GPU runtime support.

The [qualification declaration](https://github.com/rensutheart/napari-vipp/blob/v0.16.0a10/docs/release-qualification-baseline.md)
separates the changed opening, Crop presentation and reader-warning checks from
carried-forward scientific and installer evidence. A responsive preview does
not validate every image, GPU, workflow or biological interpretation. These
changes do not establish a new full installer lifecycle baseline.
