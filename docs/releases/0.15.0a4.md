# VIPP 0.15.0a4

VIPP 0.15.0a4 is a small presentation-fix release: clearer graph connections
and more readable overlapping histograms. Image-processing algorithms,
measurement values and workflow schema versions are unchanged from a3.

## Clearer connections

Wires avoid doubling back through their source or destination cards when
nodes are in the same column or a connection runs to the left. Routing also
uses available gaps around nearby nodes. Attached wires protect their endpoint
cards while dragging; routes around other cards settle when you release.
Overlapping cards can still hide connections—separate them or use **Auto
Arrange**. See [graph editing](../how-to/edit-graph.md#keep-long-graphs-readable).

## Readable overlapping histograms

The detailed histogram window draws faint channel fills first, then stepped
outlines above them. Dense vertical bin borders no longer obscure the other
channels. PNG/TIFF exports use the same style; single-channel bars are
unchanged. The plot does not smooth or change histogram values, and zero-count
bins still leave gaps on a logarithmic y axis. See
[intensity histograms](../workflows/object-measurements-tables.md#reproducible-intensity-histograms).

## Install and upgrade

Use the [canonical 0.15.0a4 GitHub release](https://github.com/rensutheart/napari-vipp/releases/tag/v0.15.0a4)
for the Windows installer, separate Apple Silicon and Intel macOS packages,
matching checksums and qualification evidence. The installers remain
explicitly unsigned; macOS packages are also unnotarized and CPU-only. Follow
[installation](../getting-started/installation.md) and verify the matching
checksum before opening an installer.

For an exact manual CPU installation, use
[PyPI 0.15.0a4](https://pypi.org/project/napari-vipp/0.15.0a4/):

```text
python -m pip install "napari[pyqt6]>=0.6" "napari-vipp==0.15.0a4"
```

On macOS use `napari[pyside6]` instead of `napari[pyqt6]`.

Workflow, batch-config and manifest schemas remain **6**. Preserve original
analyses and environments, and regenerate Python exports for the installed
VIPP version. Earlier [a3 features and compatibility boundaries](0.15.0a3.md)
remain applicable; this release does not add new nodes or broaden GPU
qualification. The [qualification declaration](https://github.com/rensutheart/napari-vipp/blob/v0.15.0a4/docs/release-qualification-baseline.md)
distinguishes checks of the changed presentation from carried-forward
scientific evidence. An alpha release is not independent validation of an
assay; recheck consequential results after upgrading.
